# 剑盾 HUD

剑盾风格 HUD 美化版，当前版本 `1.6.25`，内置弦九核心 `5.8.5`。

目标是以本地模板和样式呈现队伍、训练家、附近宝可梦及功能页面；核心提供业务和宿主接口，白天/暗色配色、字体、布局与组件由本地管理。
