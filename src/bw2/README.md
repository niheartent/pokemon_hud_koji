# 黑白2 HUD

黑白2双屏美化版，当前版本 `0.4.22`，内置弦九核心 `5.8.5`。

目标是保留黑白系列的双屏信息结构，同时让页面布局、颜色、图标与交互由本仓库独立维护。完整版支持在线检查更新；独立版不含更新器，通过重新导入升级。
