# 黑白2 HUD 美化版

当前版本：**v0.4.22**，内置弦九核心 **v5.8.5**。

黑白2版的目标是保留双屏信息组织，同时把页面、颜色、字体和按钮全部收回到本地维护。上游核心负责数据、存取、图片解析、MVU 和交互协议；本地展示层负责最终 HTML、CSS、双屏布局和页面切换，因此弦九更新不会直接覆盖黑白2的视觉样式。

## 功能

- 双屏布局：上屏展示队伍、世界、战场等主要信息，下屏提供菜单、快捷操作和关系入口。
- 队伍与盒子：统一队伍卡、属性、技能和道具信息，支持队伍与盒子之间存入、取出、换盒。
- 背包、繁育、徽章盒、图鉴、地图和克制表页面使用统一的本地设计语言。
- 克制表在页面内切换，不额外跳出窗口；属性标签、双属性倍率、抵抗和免疫沿用核心计算结果。
- 黑白版完整版保留在线更新与角色卡写回；独立版移除在线更新器，适合只想重新导入固定包的场景。
- 黑白页面的颜色、图标和资源独立打包，不读取剑盾版主题，也不依赖弦九原版 CSS。

## 安装和更新

从 [bw2-v0.4.22 Release](https://github.com/niheartent/pokemon_hud_koji/releases/tag/bw2-v0.4.22) 下载对应 JSON，在酒馆中替换旧 HUD 脚本，并确保同一时间只启用一个黑白 HUD。

完整版在设置中检查更新时，会同时检查黑白美化包和弦九核心，先验证通道、版本和 SHA-256，再由你点击安装。桌面端会按当前角色卡的存储标识写回，只替换明确标记的黑白美化脚本；原版 HUD 不会被覆盖。

独立版附件位于同一 Release 的 `bw2-v0.4.22-independent.json`。独立版不含在线更新器，升级方式是重新导入新的独立版 JSON。

## 设计目标

黑白版强调“信息分屏、操作集中、视觉稳定”：页面之间使用相同的标题、边框、按钮和间距规则；空位隐藏时保持原有布局高度；功能入口只负责调用核心业务接口，显示内容和样式由本地模板决定。
