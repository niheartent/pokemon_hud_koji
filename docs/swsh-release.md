# 剑盾 v1.7.3

- 回滚 v1.7.2 中依据网络类型、流量设置和 CPU 核数切换样式的方案；这些条件不能代表 HUD 操作是否流畅。
- 酒馆同一轮短时连续事件现在共用一个固定 50 毫秒刷新窗口，避免事件处理器重复触发整套 HUD 刷新；后续事件仍会单独刷新。
- 刷新窗口不会随着后续事件重置，最迟在首次事件后 50 毫秒触发；白天／暗色视觉效果保持原样。
- 保留剑盾本地布局、双色主题和弦九核心 v5.9.2 的功能接口。

验证：通过 VM 事件源测试验证事件爆发只触发一次刷新、不会重复绑定、后续独立事件仍会刷新；完整测试与发布校验结果以 CI 为准。该模拟测试验证刷新调度逻辑，不代表真实设备帧率测量。
