# 剑盾 v1.5.1

- 统一所有页面的基础文字、控件、输入框、卡片及选中状态到自有明暗主题；修复白天图鉴浅色文字与筛选按钮。
- 个体值标签接入明暗主题：白天为灰蓝底与深色字，黑夜为深蓝底与浅色字，描边随主题同步。
- 白天宝可梦详情改为银灰底色，修复名字的浅色文字；名字、标题强调条与存取按钮使用少量深红点缀，技能与资料文字保持清晰。
- 移除队伍普通与选中卡片上沿的白色高光；明暗两套配色均不添加上沿亮边，保留原有渐变与轻阴影。
- 预览切换箭头加粗并放大，捕获球图标由 28px 放大至 36px，收紧左右按钮间距。
- 选中队伍卡片、队伍底栏与导航栏统一使用同一石墨深灰基色；队伍卡片渐变改为从左到右轻微变浅。
- 白天队伍卡片改为柔和浅灰渐变，配合内描边、高光与轻阴影；选中卡片使用石墨深灰渐变，降低纯白／纯黑对比的突兀感。
- 放大队伍预览切换控件，中间展示当前宝可梦的捕获球种并随切换同步；未记录球种显示问号。
- 队伍卡片右侧增加留白，放大携带道具与特殊形态标识。
- 隐藏队伍空位卡片和文字，保留六个位置的布局空间，队伍区域高度不随人数缩短。
- 禁用核心自带样式初始化与 CSS 追加，仅加载剑盾自己的固定样式基础、布局和主题。
- 字体、文字、背景与边框配置随美化包维护，核心更新不再替换这些配置。
- 保留原版业务交互；上游 DOM/业务接口变更仍需兼容检查。

- 修复暗色背包与人际关系标题的强调条误用红色：暗色使用蓝色，白天保留红色。栏目强调色独立管理，避免和品牌色混用。

- 修复白天主题训练家底色与文字混用；徽章、资料说明恢复清晰对比。
- 附近宝可梦使用浅色卡片与深色文字，保留属性、稀有标识和彩色顶边。
- 背包、人际关系使用明确的卡片边框、浅灰蓝标题与红色提示边。
- 修复战场白底浅字：名字、数值、招式、各方资料及战术分层展示；增益、减益采用适合当前主题的颜色。
- 集中管理背景、正文、辅助文字、边框和状态颜色；美化 CSS 在原版全部样式生成后追加，避免在线核心更新覆盖主题。
- 首次安装默认暗色；已保存的白天选择继续保留，可在设置中切换。
- 设置仅保留白天／暗色切换，删除原版主题预设、选色、深浅及文字颜色控件；旧的自定义主题缓存不再影响固定配色。
- 修复设置标题、选项与辅助文字的白底浅字问题。
- 在内置核心和 v3.3.19、桌面与窄屏、明暗两种模式下验证；已测正文与辅助文字对比度均达到 4.5:1。

已有 v1.4.4 远程更新版可通过设置检查更新安装；更早版本可重新导入本版 JSON。
