# 代码边界

## 上游核心

`src/bw2/pkm-hud-upstream.json` 与 `src/swsh/pkm-hud-swsh-upstream.json` 是已验证的原版输入快照。保留原始版本号、业务代码与启动结构。在线核心更新从弦九原版地址下载，不能用本仓库的美化脚本充当原版输入。

存取精灵、装备、MVU 持久化、资产变更保护、数据与图片解析由核心负责。界面适配不绕过其业务保护。

## 黑白2

`bw2-core-adapter.js` 为本地构建和浏览器更新共用的适配器。Acorn 从当前原版源码定位函数与样式初始化；局部交互仍检验必要片段，接口变化时拒绝安装。

`bw2-native-base.css` 固定已接受的原版视觉基础；bw2 CSS/JS 模块负责双屏布局、队伍与详情展示、页面路由与局部刷新。

独立版构建器裁剪原版冗余展示、兼容包和在线更新器，保留业务依赖。它没有远程更新入口。

## 剑盾

`swsh-compat.js` 用语法定位注入美化层。`swsh-adapter.js` 装饰原生 HTML，保留核心原生函数调用与新增内容。`swsh-beauty.js`、CSS 和 SVG 提供界面。

`swsh-colors.css` 集中管理训练家、附近卡片、折叠栏目与战场的颜色角色；`swsh-hud.css` 管理布局和其余展示。主题的背景、文字、边框和状态颜色成组切换。兼容器分别注入运行时与样式：运行时在原版 CSS 初始化后进入作用域，美化 CSS 在原版所有 CSS 追加完成、写入 style.textContent 前追加。该节点缺失或重复时拒绝合成，避免更新后静默失去主题。

配色规则及验证范围见 [剑盾主题管理](SWSH-THEMES.md)。

## 共享更新机制

`koji-updater.js` 同时检查两个来源。下载的新美化包必须来自指定仓库、SHA-256 匹配、通道匹配，才调用其中的合成器。合成器只生成文本，不启动候选 HUD。语法和接口验证完成后开放安装按钮。

`koji-bootstrap.js` 允许同核心版本的新美化缓存启动，也允许更新核心搭配同等或更新的美化层；拒绝旧美化覆盖新手动导入版本。两版使用独立、稳定的 IndexedDB 名称，连续在线升级不会丢失后续安装记录。

`updates/*.json` 只指向已经发布的标签中的文件；`versions/` 保存对应脚本。打包工具禁止以不同内容覆盖同一个已存在版本。

## 验证范围

测试使用隔离的模拟酒馆/MVU。远程更新回归使用浏览器真实 IndexedDB，验证刷新、连续美化更新、健康标记及校验与通道隔离；不操作用户的真实角色卡。
