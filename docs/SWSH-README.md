# 剑盾 HUD 美化版

当前版本：**v1.6.25**，内置弦九核心 **v5.8.5**。

剑盾版的目标是以剑盾风格重新组织 HUD：核心只提供数据、图片、业务处理和宿主交互，本地模板负责队伍、训练家、附近宝可梦、详情和所有页面的最终渲染，避免弦九更新把原版 CSS 或模板重新带回来。

## 功能

- 队伍卡和附近宝可梦使用本地布局，保留血条、性别、携带道具、Mega、超极巨、头目、闪光和搭档倾向标识。
- 训练家、人际关系、背包、盒子、繁育、徽章盒、图鉴、地图、世界和战场页面统一使用本地组件和颜色变量。
- 白天与暗色两套主题独立保存；默认使用暗色，切换白天只改变本地主题，不复用弦九的调色设置。
- 设置页只保留明暗主题和 HUD 宽度等必要选项，不开放原版主题预设、色相或文字颜色控制。
- 详情页属性和技能卡尺寸统一，图标、箭头、选中态和空位布局由本地 CSS 管理。
- 更新器会校验美化包通道、版本、SHA-256 和核心兼容性；新版核心不兼容时不会强行覆盖当前版本。

## 安装和更新

从 [swsh-v1.6.25 Release](https://github.com/niheartent/pokemon_hud_koji/releases/tag/swsh-v1.6.25) 下载 `swsh-v1.6.25-hud.json`，导入酒馆并替换旧脚本，确保只启用一个剑盾 HUD。

在设置中检查更新后，先检查美化版，再检查弦九核心并生成已验证的组合脚本。点击安装后，桌面端按当前角色卡的存储标识写回，只更新明确标记的剑盾美化脚本；原版 HUD 和其他角色卡保持不变。

## 设计目标

剑盾版强调“本地渲染、语义配色、稳定升级”：白天和暗色各自拥有完整的背景、文字、边框、按钮和强调色；所有页面共享同一套间距、圆角、层级和交互状态。核心更新只接入功能接口和新数据字段，不接管最终样式。
